# Forest Department App

A simple forest department incident reporting application with:

- Map support using browser geolocation and Leaflet markers.
- Mobile-friendly navigation and responsive layout.
- Backend API for shared report storage using Node.js and Express.

## Setup

1. Open a terminal in `forest-department-app`
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000`

## Features

- Report incident form with location and description.
- Live incident map for GPS-based reports.
- Sync reports to the backend and load shared reports.
- Mobile nav and responsive layout.
