Database Management Systems

Instructions: Answer all questions in Part A. Answer any five questions from Part B. Draw neat diagrams wherever necessary.

Part A - Answer All Questions (10 x 2 = 20 Marks)

  1. Define DBMS. 2
  2. What is a primary key? 2
  3. List any two advantages of normalization. 2
  4. Write the syntax for creating a table in SQL. 2
  5. What is data independence? 2
  6. Differentiate DDL and DML. 2
  7. Define entity and attribute. 2
  8. What is a foreign key? 2
  9. State the purpose of indexing. 2
  10. What are ACID properties? 2

Part B - Answer Any Five Questions (5 x 16 = 80 Marks)

  1. Explain the architecture of a database management system with a neat diagram. 16
  2. Design an ER diagram for a college examination system and explain the entities, attributes, and relationships. 16
  3. Explain 1NF, 2NF, and 3NF with suitable examples. 16
  4. Write SQL queries using joins, grouping, aggregate functions, and nested queries for a student database. 16
  5. Discuss transaction management, serializability, and concurrency control techniques. 16
  6. Explain file organization and indexing methods used in database systems. 16
  7. Describe recovery techniques and log-based recovery in detail. 16
