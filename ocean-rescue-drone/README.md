# Ocean Rescue Drone System

A starter web dashboard for an ocean rescue drone system. This project can be extended into a real rescue operations app with live GPS tracking, emergency request forms, backend mission management, and integration with drone telemetry.

## Files

- `index.html` — dashboard interface
- `styles.css` — app styling
- `app.js` — mission simulation and drone status updates

## Run locally

Open `index.html` in your browser, or use a local static server for best results.
